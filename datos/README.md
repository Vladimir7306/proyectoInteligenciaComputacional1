# Datos del grafo

Guarda en esta carpeta el archivo grafoCETYS.json descargado con Exportar JSON desde editorCETYS.html.

Antes de exportar, guarda los cambios de los formularios. Para compartir el grafo, agrega datos/grafoCETYS.json al commit y haz push. Tus compañeros deben actualizar el repositorio e importar ese archivo desde el editor.

El guardado automático del navegador no modifica este archivo. Después de editar, vuelve a exportar y reemplaza el JSON de esta carpeta.
